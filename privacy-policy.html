Ask your GIT — Privacy Policy

Last updated: November 3, 2026

Overview

Ask your GIT is a browser extension that adds an AI assistant to GitHub, GitLab, and Bitbucket repository pages. It can summarize a repository, answer questions about it, and copy or launch install commands for local coding tools.

What data the extension sends, and where

The extension only sends data when you use an AI feature (Quick Summary or Ask AI). It never runs in the background on other websites and does not collect your browsing history.

  • Repository content you are viewing (repository name, description, topics, file list, languages, and up to 4,000 characters of the README) and the questions you type into the chat are sent to generate the AI answer.
  • By default this goes to our AI proxy at vercel-nu-wheat.vercel.app, which forwards it to Anthropic's Claude API and returns the answer. The proxy sees your IP address and a random installation ID (generated on install, not linked to your identity) and uses them only for rate limiting. The proxy does not store the content of your requests or answers.
  • If you add your own Claude API key, requests go directly from your browser to api.anthropic.com and are governed by Anthropic's privacy policy. Your key is stored only on your device (chrome.storage.local) and is never sent to us.
  • To build repository context, the extension calls the public GitHub API (api.github.com) for the repository you are viewing. No GitHub credentials are used or read.

We do not sell data, use it for advertising, or use it for any purpose other than answering your request. We do not use analytics or tracking.

Data stored on your device

  • Preferences (default tool, custom commands, emoji pack, terminal choice) in chrome.storage.sync, which Chrome may sync across your own browsers.
  • Local usage counters (number of summaries, chats, installs, and the last 100 repository paths you analyzed) and emoji card share history (last 10 shares), in chrome.storage.sync. These are shown to you in the popup and are never sent to us.
  • Your optional Claude API key and the random installation ID, in chrome.storage.local.

Removing the extension deletes this data.

Permissions

  • storage: save your preferences and the data listed above.
  • clipboardWrite: copy install commands to your clipboard when you click a tool.
  • nativeMessaging: optionally send an install command to your local terminal through the separately installed Ask your GIT Companion. Nothing is sent unless you install the companion and click an install button.
  • Host access to api.github.com, api.anthropic.com and our AI proxy: fetch repository info and AI answers, as described above.
  • Content scripts on github.com, gitlab.com and bitbucket.org: show the Ask your GIT button on repository pages.

Sharing

Share buttons (Telegram, WhatsApp, X) open the service's standard share page in a new tab. Nothing is posted until you confirm there.

Native Messaging Host

The optional companion runs locally on your Mac and opens your terminal with a command you clicked. It only accepts commands matching a strict allowlist (git clone, claude, codex, open) and does not communicate with any external server.

Open Source

This extension is fully open source. You can review the complete source code at github.com/pirajoke/askyourgit.
